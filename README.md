# B站音乐小节线 · Chrome 扩展

由 https://github.com/m1ku666/bilibili-evolved-barline 改造的独立 Manifest V3 扩展，无需安装油猴或 Bilibili Evolved。

## 安装

### 本机固定目录（推荐）

本项目的 `dist/` 已经是可直接加载的扩展目录，无需解压。首次在 Chrome 的 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择：

```text
C:\Users\Wight\Documents\Codex\2026-09-28\https-github-com-m1ku666-bilibili-evolved\outputs\barline-chrome\dist
```

以后更新会直接构建到这个目录，你只需在扩展管理页点击「重新加载」，再刷新 B 站视频页。请保留此目录，不要移动。如果之前加载的是自行解压的文件夹，需要先切换到这里一次；已有配置可先通过面板「管理」标签导出，然后在新加载的扩展中导入。

### ZIP 安装方式

1. 解压 `bilibili-barline-chrome.zip` 到固定文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 刷新已经打开的 B 站视频页。鼠标移入播放器，底部播放时间右侧显示小节线按钮；悬停图标可查看名称。最左边的图标打开「小节线面板」。

如果使用源码文件夹，则直接加载 `dist` 子目录。移动或删除已加载的文件夹会导致扩展失效。更新时覆盖文件后，在扩展管理页点击重新加载，再刷新视频页。

## 使用

### 小节线面板（1.8.0）

所有功能集中在一个可拖动、可缩放的面板里，不再弹出单独的设置和管理窗口。播放器底部最左边的图标打开面板；扩展弹出页的「节拍设置／抄谱／管理」会直接打开对应标签页。

- **小节线**：最上面是「从谱面自动对齐」（自动推算小节时间和 BPM，一键应用到节拍器），下面依次是小节定速（起点／下一节）、速度与拍号表、打拍子。只是打开查看不会建立配置，修改任意一项才会保存。
- **抄谱**、**段落**、**练习**：同前。
- **管理**：所有视频的小节线配置，可搜索、排序、删除、导出和导入，当前视频会标出。
- 再点一次当前标签，或点标签栏右侧的 ⌃，即可收起功能区；点 ⤢ 让功能区占满面板（暂时隐藏谱面），再点恢复。
- 面板标题旁显示当前视频的节拍（如「100 BPM · 4/4 · 已校准」）。控制栏「起点／下一节」、自动对齐、音量的改动会实时同步到面板里，正在标记的小节点不会丢失。
### 自动分析音频、段落与练习收藏（1.4.0）

- **自动分析**：小节线面板「抄谱」标签中框选一行谱面→勾选「同时分析节拍」并设置8秒至10分钟的范围和拍号→「开始抄谱」。原速播放一遍，同时在本机提取音频起音强度、估计BPM与节拍，检测谱面换行、细蓝绿色光标和跨谱线小节线。不上传音视频，不需要Python或云服务。期间保持标签页在前台；会暂时取消循环、静音节拍器，结束恢复视频时间、速度、静音及原播放状态。停止时保留已抄部分；节拍分析需已抄范围至少8秒。
- 显示BPM候选、可信度和小节对齐状态；匹配到连续的至少3个视觉小节边界且可信度较高时，可以自动应用局部小节速度。其他情况需点击「应用并替换小节轴」或使用底部「起点／下一节」校准。自动结果不能保证正确重拍、拍号或自由速度，拍号需手动设定；未发现视频光标时的红线标为“音频辅助估算”，不是音符识别。支持导出JSON时间轴。
- **手动段落**：小节线面板「段落」标签。定位视频后点击「前奏、A段、A1、A2、B段、B1、B2、间奏、尾奏」即可标记。可改名称、颜色、起点，支持自定义段落；每段持续至下一段开始。顶部彩色按钮可定位，播放时高亮当前段落，谱面上显示彩色起点标记。段落独立于节拍器的变速分段，自动重新截谱不会删除手动段落。
- **摘录收藏**：展开「摘录与练习收藏」，用当前时间设置起止点，或「取当前段落」，填写名称后「收藏谱面与片段」。保存原视频链接、绝对起止时间、独立谱图快照、定位点和BPM配置；之后重新生成谱面不会改变已有收藏。列表包含所有视频的收藏，点击其他视频收藏可返回对应视频。
- **原伴奏练习**：直接播放原B站视频的选定时间区间，不录制、转码、归一化或重新混音。保持播放器音量、使用1倍速，暂时关闭额外节拍器声；结束暂停，退出后恢复原速度。谱图沿用原时间坐标，即使从谱行中间摘录也不会重新拉伸定位线。收藏的时长严格保存为结束时间减起始时间；实际停止/循环边界受浏览器调度与视频缓冲限制，不是音频采样级裁剪，不承诺无缝循环或硬件零延迟。
- BPM标记为“已按小节校准”仅表示该配置来自底部两个相邻小节起点，且未被其他速度修改；其他来源显示“待核对”。准确度仍取决于手动点位和原演奏是否变速。原片段播放完全跟随原音轨，不依赖估算BPM进行变速。
- 收藏是本机书签与谱图，不是离线音视频文件，播放依赖原视频可用和网络加载。可在原视频正常播放时收藏，不绕过登录或视频访问条件。

### 抄谱、固定谱窗与定位线（1.5.0 起）

1. 打开小节线面板，切到「抄谱」标签。下方始终是谱面。
2. **① 框选谱面**：在画面上拖框，或点「上方／下方／全画面」。框下方会立即提示“框内像谱面／没有深色内容／包含演奏画面”，以及是否发现播放光标。尽量只框一行谱。
3. **② 范围**：开始、结束可输入秒数或 `m:ss`，也可「取当前」「整个视频」「从当前到结尾」。
4. **③ 方式**：默认 4× 静音快速播放一遍（2× 更稳，1× 原速）；勾选「同时分析节拍」则原速有声播放并估算 BPM。点「开始抄谱」，进度条旁可随时「停止（保留已抄部分）」。
5. 抄谱时每一帧都在小画布上比较音符（忽略谱线、光标、浅色高亮，容忍1像素抖动），画面稳定后才截取一张高清图，因此：
   - 换行时刻精确到帧，淡入淡出的过渡帧、单帧闪烁不会变成多余的行；
   - 已演奏音符变色不算换行；音符逐个显现时保留同一起点，并更新为最完整的一张；
   - 片头、空白等非谱面画面会结束当前行，不再拉长上一行；短暂遮挡后同一行会续上；
   - 识别到任意颜色的细播放光标时，用稳健拟合（剔除误检、保证从左到右）生成定位点；光标在同一谱面跳回左侧（反复记号）会拆成新的一行。
6. **自动小节对齐（1.7.0）**：没有播放光标的行，不再按宽度匀速移动，而是用截谱时识别的小节线，把这一行的时长平均分给各小节（同一拍号下每小节时长相同，与小节画得宽窄无关）。抄谱后、打开谱窗时、编辑谱行后都会自动进行，行标签显示「小节对齐」。
   - 时长与小节数对不上的行（反复记号、漏识别小节线、前奏）保持原样，「节拍」标签页列出原因。
   - 视频常提前显示下一行：只要任意一行有播放光标，或你在任意一行「校准」两个点，就会测出提前量并修正全部估算行。
   - 「应用到节拍器」把对齐得到的小节网格写入节拍器（按拍号换算 BPM，变速处自动分段），无需手动点「起点／下一节」。
   - 定位线整体偏早或偏晚（蓝牙耳机延迟、视频音画不同步）时，用谱窗中部的「− 0 ms ＋」整体调整，点数字归零。
   - 需要谱面上有贯穿五线谱或六线谱的小节线；识别不到小节线的行仍为均匀估算。
7. **只替换抄写范围内的谱行**，范围外的保留，可分段抄写。每行工具栏显示起止时间和定位方式（光标定位／小节对齐／节拍估算／手动校准／均匀估算），可「跳到此行」「起点=当前」「重抄」（只重新抄写该行时间段）「清除定位」「删除」。
8. 漏了换行就把「换行灵敏度」调高后重抄该段；多出碎行就调低。没有光标的视频可勾选「校准定位线」：暂停后在谱图上点击对应位置绑定当前时间，每行至少两点。
9. 谱窗可拖动、缩放、「锁定」位置；「跟随」同步滚动到当前行并显示红色定位线；点击谱图跳转视频。底部「导出」菜单包含长图 PNG、PDF／打印（带行号、时间和段落标签）、下载备份和恢复备份。界面跟随系统浅色／深色模式。
谱图和校准存于扩展自身的 IndexedDB，每行图片单独存储，平时保存（拖动谱窗、改设置、校准）只写入变化的部分，按 BV/AV 路径和分 P 分开；刷新页面后恢复谱窗显示状态、位置和内容。卸载扩展会清除数据。截图只在本机处理，不上传、不下载远程脚本，也无需 Python 服务。画质取决于播放器实际清晰度；若视频跨域策略不允许读取，会提示错误，可改用图片导入。扫描时请留在当前视频页，切换视频会取消扫描。多行谱面或没有播放线的视频建议按行截取并手动校准。

这是参考 BiliTabCapture 的浏览器端截谱流程，不包含其本地视频下载、PDF 文档导入或 OpenCV 全套小节线识别。定位线优先使用源视频位置或人工校准，未校准的估算不保证与音符精确对应。

### 小节线与节拍器（1.6.0）

- **小节定速**：在一个小节开头点底部「起点」（<kbd>Alt+1</kbd>），之后每到下一小节开头点「下一节」（<kbd>Alt+2</kbd>），可连续点多个小节。每多一个标记都会用全部标记做线性回归，手点误差被平均掉，并提示“N 小节平均 · 最大偏差 x ms”；漏点一个小节会自动按两小节计算。面板「小节线」标签里也可逐个查看、删除或手动输入标记。没有配置时默认 4/4，其他拍号先在设置中调整。
- **节拍器**：提前约 0.12 秒按音频时钟排程点击，精确到毫秒，不受掉帧影响；标签页在后台时加大预读，不会停响。暂停、拖动、变速时立即取消未发声的点击并重排。点击音峰值不超过满幅，不再破音。按钮 <kbd>Alt+M</kbd> 切换，悬停调节音量。
- **预备拍**跟随播放速度：0.5× 练习时预备拍同样放慢。
- **循环**（<kbd>Alt+L</kbd>）：依次设置起点、终点、关闭。起点和终点所在小节都包含在内；同一小节点两次即循环这一小节。按视频帧检测终点，不再多播出下一小节的开头。进度条上高亮循环区间。
- **循环加速**：在扩展弹出页设置「每遍加速」（2%/5%/10%）和目标速度，每循环一遍自动提速，关闭循环后恢复原速度。
- **方向键**：默认 ←／→ 跳上一／下一小节；弹出页可改为 Shift+←／→（保留 B 站原有的快进快退）或关闭。输入文字时不接管按键。
- 面板「小节线」标签中设置 BPM、拍号和第一拍位置，修改即时生效并自动保存；第一拍可用 ‹ › 前后移一拍。「从当前小节起变速 / 变拍号」可加段落。BPM 以四分音符为单位，6/8 拍的每拍时长为 `60/BPM × 4/8`。「打拍子」后可直接「应用到第 1 段」。
- 触屏横向滑动可按小节跳转。面板「管理」标签支持搜索、排序、删除、JSON 导出与导入。
## 支持范围与数据

支持 `https://www.bilibili.com/video/` 普通 BV/AV 视频页及分 P；播放器全屏时工具栏随播放器显示。直播、番剧、嵌入式播放器暂不支持。

配置按视频 CID 分开保存在 `chrome.storage.local`，与原油猴存储相互独立。B 站视频信息接口不可用时，会使用 `BV号:p页码` 作为备用键；接口恢复后如未自动匹配，请通过管理面板备份并重新配置。卸载扩展会清除本地数据，建议先导出备份。

权限只有 `storage` 与 B 站视频信息 API；内容脚本仅注入 `www.bilibili.com`，用于检测站内跳转。视频元信息请求由后台发往固定 API，不加载远程 JavaScript，不需要 `eval`。

## 从源码构建

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm test
npm run build
```

`dist/` 是可直接加载的扩展。Vue 模板在构建时预编译，Vue 运行时及样式均打包在本地。`src/chrome-adapter.ts` 替代原框架接口，`src/storage.ts` 替代 GM 存储，`public/` 包含 Manifest、后台和工具栏弹出页。
